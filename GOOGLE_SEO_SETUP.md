## 🚀 Google Search Console Setup

### **Step 1: Add Property**
1. Go to [Google Search Console](https://search.google.com/search-console)
2. Click **"Add Property"**
3. Choose **"URL Prefix"**
4. Enter: `https://www.gogethires.com`

### **Step 2: Verify Ownership**
Choose one of these methods:

**Option A: HTML File Upload (Recommended)**
1. Download verification file from Google
2. Upload to `/public/` folder in your project
3. Deploy to Vercel
4. Verify in Google Search Console

**Option B: Meta Tag Method**
1. Copy meta tag from Google Search Console
2. Add to `app/layout.tsx` in the `<head>` section
3. Deploy and verify

### **Step 3: Submit Sitemap**
1. In Google Search Console, go to **"Sitemaps"**
2. Add sitemap URL: `https://www.gogethires.com/sitemap.xml`
3. Click **"Submit"**
